# TokenBuddy Tray

一个**跨平台(Windows / Linux / macOS)的 AI 中转站余额托盘小工具**。托盘图标同时显示**站点名**和**余额金额**,点开可看今日消费、已用额度与站点详情。

- **开源免费(MIT)**、单文件即可运行、双击就用。
- **只填 API Key 的 BASE URL**就能自动识别协议;Sub2API 填 API Key 即可读余额,需要登录的站点再填账号密码。
- 适合 **Sub2API / New API(One API) 系**中转站,并支持部分专用站点适配;认不出来的协议走**能力探测**或**手填接口路径**。

> 这是一个开源的小工具,用来让用户随时看到自己的余额还剩多少。

---

## 它解决什么问题

中转站的余额通常只能登录网页才能看到。这个小工具常驻系统托盘,**一眼就能看到余额**,余额偏低时图标变色提醒,免去反复登录。

## 特性

- 托盘图标为普通应用图标,点击打开面板、右键菜单;Linux 面板会把宽图标强制缩进正方形,托盘里放不下大号余额,因此余额用**顶栏余额条**显示(见下)。悬停托盘仍提示站点名和完整余额。
- **顶栏余额条**(可在设置里开关):一枚可拖动的大号余额牌贴在顶栏旁,数字完全不变形;余额偏低自动变色:绿(充裕)→ 琥珀(偏低)→ 红(接近 0)。大小(60%–250%)、背景色、数字颜色、自定义缩写(如 TB / APP)、圆角(0=直角)都能在设置里调。
- 悬停托盘显示 `站点 · 余额`;左键点开面板看今日/累计消费。
- 币种按站点自己的口径显示(`$` / `¥`),不一律印美元符号;完整币种保留在提示、面板和余额牌中。
 - 多站点:可同时配置多个中转站,随时切换。
 - 定时自动刷新(默认 120 秒,可调)。
 - 余额请求走系统网络栈,自动跟随系统代理设置(Linux GNOME/KDE、macOS、Windows);需要代理的站点只要系统代理可用即可正常读取。
- New API 首次登录后会完整保存 Access Token、旋转式 Refresh Cookie 与会话 SID;短令牌过期后调用官方刷新接口续期,不会重新登录。专用站点登录令牌同样复用。定时轮询没有可用会话时绝不自动登录;只有保存设置或手动刷新才允许登录一次。遇到 `429`、服务器错误或网络异常时保留原会话并停止登录。
- 凭据只存本机;可用时用系统安全存储(Electron `safeStorage`)加密。
- **桌面宠物**:可换成任意图片(包括宝宝照片)、GIF 动图或 WebM 视频;自动待机动画;透明处鼠标穿透;头顶气泡同时显示站点名与余额。

## 桌面宠物

一个透明、无边框、始终置顶的小家伙待在桌面上,头顶悬浮实时余额。

- **形象完全自定义**:设置里「选择图片」,支持 `PNG / JPG / GIF / WebP / APNG / SVG / WebM / MP4`。
  - 静态图(如宝宝照片)自动加待机动画(轻微起伏/呼吸),点一下会蹦跳;
  - GIF / WebM 直接播放原生动画。
  - 不选时使用内置的宝宝素材,并按状态切换表情(见下表)。
- **状态表情**:默认形象按真实数据切换,不为了好看伪造状态。

  | 状态 | 触发条件 |
  |---|---|
  | 欢呼 | 余额正常 |
  | 伤心 | 余额为 0 |
  | 捧着硬币 | 余额偏低(0 < 余额 ≤ 1) |
  | 比个心 | 无限额度 Key |
  | 盯着沙漏 | 正在刷新且还没有可用余额 |
  | 转圈圈 | 读取失败 |
  | 摊手疑问 | 余额读不到 |
  | 蹦跳 | 单击后约 1.8 秒 |
  | 被拎起来 | 拖动中 |

  已有可用余额时,后台定时刷新不会改变表情,避免每隔一段时间闪一下。默认形象是
  戴薄荷绿围巾的黑白猫,随程序一起提供默认素材。
  这 9 张都加载失败时才退回内置 SVG 吉祥物,并在控制台打印错误。
- **操作**:拖动移动;左键点一下蹦一下并弹出余额面板;右键出菜单。
- **透明穿透**:形象透明区域鼠标事件穿透到桌面,只有形象本体和气泡可点(逐像素命中检测)。
- **右键菜单**:更换形象、大小(100–420px)、显示余额气泡、始终置顶、左右翻转、开机自启、打开余额面板、隐藏、退出。
- **余额气泡**:实时显示当前站点余额;余额偏低(≤$1)变红提醒。
- **开机自启**:Windows/macOS 用系统登录项,Linux 写 `~/.config/autostart/`。

> Sub2API 若关闭了 `/v1/usage`,可在「高级」里改用**邮箱 + 密码**登录读取。

## 详细操作

### 添加和编辑站点

1. 打开托盘菜单中的**设置…**,点击**添加站点**。
2. **站点名称**只用于托盘提示和列表显示,可以填写任意容易辨认的名称。
3. **API Key 的 BASE URL**填写 API Key 所属服务的请求根地址。可以填写以下任一种:
   - 服务根域名,例如 `https://example.com`;
   - 单独的 API 子域名,例如 `https://api.example.com`;
   - 已经包含版本前缀的地址,例如 `https://api.example.com/v1`。
4. 不要把完整的聊天接口路径、控制台页面路径或带查询参数的链接当作 BASE URL。程序会自动补齐余额接口需要的路径,也会去掉查询参数和片段。
5. 从服务后台复制 API Key,粘贴到**API Key**字段。除非识别结果要求登录,否则不需要再填账号密码。
6. 点击**保存**。地址发生变化时,设置页会重新识别协议并显示探测结果。

### 选择和刷新

- 托盘左键打开余额面板,右键打开菜单。面板会显示当前站点、余额、今日用量、累计用量和最近一次更新时间。
- 配置多个站点后,在托盘菜单或面板下拉框切换当前站点。每个站点独立保存 BASE URL、凭据和刷新结果。
- 程序默认每 120 秒刷新一次,可在设置中调整。也可以在托盘菜单中手动刷新。
- 新 API 登录会话会自动复用和续期;遇到限流时程序会等待冷却,不会连续重复登录。

### 开机启动

托盘图标右键菜单中的**开机自启**控制整个 TokenBuddy 软件,包含托盘、余额面板和桌面宠物。设置页不再单独提供“桌面宠物开机启动”选项。

- Windows 和 macOS 使用系统登录项;
- Linux 写入当前用户的 `~/.config/autostart/`;
- 再次点击同一菜单项即可关闭。开关状态会在菜单中显示。

### 桌面宠物和余额条

- 在托盘右键菜单打开或隐藏桌面宠物,可设置大小、置顶、左右翻转、余额气泡和自定义图片或视频。
- 宠物右键菜单可打开余额面板、切换形象和退出程序;开机自启仍由托盘图标菜单统一管理。
- 设置中的**余额条**可显示在桌面顶层,支持拖动、缩放、背景色、数字颜色、缩写和圆角。它与托盘使用同一个当前站点和余额。

### 识别失败时的处理顺序

1. 确认填写的是 API Key 的 BASE URL,不是官网首页或登录页面。
2. 如果服务使用 API 子域名,直接填写 API 子域名;程序会在同站根域名和子域名之间安全跟随跳转,跨站跳转不会转发 API Key。
3. 如果服务需要登录,按识别提示填写用户名和密码并保存。
4. 打开「高级」查看探测记录。未知协议可以先使用**能力探测**,也可以填写自定义余额接口路径并点击**测试自定义接口**。
5. 自定义接口失败时,程序会显示真实 HTTP 状态和响应字段,不会静默改用其他接口。

### 凭据和配置位置

- 配置保存在 Electron 的 `userData` 目录,每个系统一个独立配置文件。
- API Key、密码、登录令牌优先使用系统安全存储加密;系统不支持时才使用本地明文保存,界面会提示。
- 程序只请求余额、用量和登录所需接口,不会代理模型请求,不会把凭据上传到第三方。

## 自动适配原理

绝大多数中转站是 One API 家族的两套协议。**程序只凭 API Key 的 BASE URL 做未鉴权探测**来判断是哪一套,不消耗你的任何凭据:

| 探测请求 | New API 家族 | Sub2API |
|---|---|---|
| `GET /api/status` | `200`,返回站点配置 | `404` |
| `GET /v1/usage`(不带 Key) | `404` | `401` + `API_KEY_REQUIRED` |
| `POST /api/v1/auth/login`(空参数) | `404` | `400`(参数校验错,说明路由存在) |

部分专用站点使用公开的 `GET /configs` 识别,登录后通过专用账户接口读取顶层余额。它们不属于 New API,因此使用独立适配器,不会硬套 New API 接口。

同一协议家族的不同部署通常共用这些端点,因此程序按接口行为识别,不会要求用户选择某个具体站点品牌。

识别之后按各自口径取值:

| 协议 | 接口 | 取到的字段 |
|---|---|---|
| **Sub2API** | `GET /v1/usage`(Bearer API Key) | `balance` / `remaining`——**账户钱包真实剩余** |
| **New API 家族**(Key) | `GET /v1/dashboard/billing/subscription` | `hard_limit_usd`——**总额度,不是余额**(见下) |
| New API 家族(Key,已用) | `GET /v1/dashboard/billing/usage` | `total_usage`(单位:分) |
| **New API 家族**(登录) | `POST /api/user/login` → 响应里的 `data.user` | `quota`(剩余)、`used_quota`(已用) |
| **专用站点适配** | 专用登录接口 → 账户接口 | `balance` |

## 没见过的协议怎么办

上面没覆盖到的站点,按下面两级兜底,**不会直接判死**。

### 1. 能力探测

协议探测全部落空时,拿你的 API Key 依次试下面这几个余额接口,**谁返回合法余额就用谁**:

```
GET /v1/usage                        →  balance / remaining
GET /v1/dashboard/billing/*          →  hard_limit_usd(总额度,自动减已用)
GET /api/v1/auth/me                  →  data.balance
GET /api/usage/token/                →  balance / remaining / quota
GET /api/user/self                   →  data.quota
```

- 每一步都严格校验响应形状,校验不过就试下一个;
- **命中的是哪个接口会如实显示**在徽章和面板上,不会冒充成 Sub2API 或 New API;
- 首次命中后协议会记住,之后刷新不再重复试探;
- 五个全部落空时,**报错会列出每个接口的真实 HTTP 状态**,不会假装成 0。

### 2. 手填接口路径

能力探测也读不到时,在设置的「高级」里自己填:

| 字段 | 说明 |
|---|---|
| 余额接口路径 | 填了就**以它为准**:不识别协议、不做探测。路径里写 `{{key}}` 会替换成你的 API Key |
| 余额字段 | 按点号路径取值,如 `data.wallet.remain`。留空则只找顶层的 `balance` / `remaining` / `quota` |
| 余额接口认证 | Bearer API Key / URL 参数 `key=` / 不需要认证 |
| 币种 | 留空按站点响应;都不给就印裸数字 |

填了路径却查询失败时,**会如实报出 HTTP 状态和响应内容,不会偷偷换别的接口**。旁边有「测试自定义接口」按钮可以先试一次。

## 币种为什么可能不显示符号

程序**不擅自假定币种**:

- New API 的 `/api/status` 会公布 `quota_display_type`(`USD` / `CNY` / `TOKENS`),按它显示;
- 某些兼容部署的 `/api/status` 不公布币种字段,只知道「按货币显示」还是「按 token 显示」,不知道是美元还是人民币。这时印裸数字,比印一个可能错的 `$` 诚实;
- 需要符号就在设置里填「币种」,填了以你填的为准。

顺带说明一个容易误解的点:New API 的 `hard_limit_usd` 虽然带有 `_USD` 后缀,**返回值已经按站点展示类型换算过**。因此程序不做二次换算。

## 为什么 New API 必须填账号密码

这是本工具唯一需要你多填两项的地方,原因来自 New API 自己的计费口径,不是本工具的限制。

**用 API Key 查不到账户余额,只能查到"这把 Key 自己的额度"。** New API 的计费接口按以下口径返回:

- `hard_limit_usd = (剩余额度 + 已用额度) / QuotaPerUnit`,也就是**总额度**,不是剩余余额;
- 真正的余额要自己用总额度减去已用额度才算得出来;
- **如果这把 Key 是无限额度,服务会把 `hard_limit_usd` 固定写成一个哨兵数字**,这个数字和你的真实余额毫无关系。

换句话说:一把无限额度的 API Key,在 New API 里**根本查不到账户还剩多少钱**。而账户真实余额只存在登录用户的 `quota` 字段里,这个字段只有登录后才能读到——所以 New API 站点必须填账号密码。

**Sub2API 则不需要登录**:`GET /v1/usage` 直接返回账户钱包的真实剩余余额,一把 API Key 就够。

首次登录走的是**纯 HTTP 请求**,**不会启动浏览器**。新版 New API 返回短期 Access Token、HttpOnly Refresh Cookie 和会话 SID;程序将三者保存在本机安全存储。日常刷新先读取 `GET /api/user/self`,短令牌失效后调用 `POST /api/user/auth/refresh` 旋转会话,不会重新创建登录会话。只有服务端明确返回 `401` 才清除失效会话;`429`、`5xx` 和网络异常均不会清除或触发登录。

专用站点适配使用登录接口获取令牌,后续只调用账户接口;令牌失效后同样只在用户手动保存设置时登录一次。

## 多站点

可在设置里添加多个站点,托盘菜单/下拉框切换当前站点,图标与面板跟随切换。

## 安全与隐私

- 配置文件在系统 `userData` 目录(`config.json`,权限 `0600`):Windows `%APPDATA%\TokenBuddy\`、Linux `~/.config/TokenBuddy/`。
- API Key / 密码优先用 Electron `safeStorage` 加密存储;不可用时明文保存,界面会提示。
- 本工具**只读取余额与用量**,不代理、不转发任何模型请求,不上传任何数据到第三方。

## 常见问题

- **显示"读取失败"**:BASE URL 填错,或该站点不属于已知协议、能力探测也读不到余额。报错里会列出每个接口的真实 HTTP 状态;这时到「高级」里**手填余额接口路径**即可。程序会在「高级 → 协议」里显示探测结果。
- **提示 429 / 登录接口冷却**:服务端正在限流,程序会停止继续登录请求并等待冷却时间;不要连续点击刷新或重复保存设置。冷却结束后再手动刷新一次。
- **New API 站点图标金额显示 `--`**:说明这把 API Key 是无限额度,读不到真实余额。按上面的说明填账号密码即可。
- **币种显示 `¥` 而不是 `$`**:New API 的 `quota_display_type` 是 `CNY` 时余额就是人民币,程序按站点自己的口径显示,不做换算。
- **余额数字前面没有货币符号**:服务没有在 `/api/status` 里公布币种,程序不猜。到「高级 → 币种」填上就显示符号了。
- **Linux 桌面不显示托盘图标**:GNOME 需安装 AppIndicator 扩展(如 `gnome-shell-extension-appindicator`);或使用 KDE / XFCE 等原生支持托盘的桌面。
- **Linux 启动即退出并提示 `GPU process isn't usable`**:用 `--disable-gpu` 启动(受限环境或 Wayland 下常见)。
- **Linux 安装后从应用列表点开没有显示、终端提示 Chromium sandbox 错误**:这是 AppImage 在部分系统上无法设置 Chromium sandbox helper 的 setuid 权限。当前版本的 Linux 开机自启会默认带 `--no-sandbox`,手动启动也可执行 `TokenBuddy-*.AppImage --no-sandbox`;如果系统已正确配置 helper 且希望恢复沙箱,设置环境变量 `TB_ENABLE_SANDBOX=1` 后重新在应用设置中开启开机自启即可。

```bash
npm run dist:win     # NSIS 安装包 + 免安装 exe(在 Windows 或 CI 上执行)
npm run dist:mac     # dmg + zip(必须在 macOS 上执行)
```

推 tag 会触发 GitHub Actions 自动为 **Windows / Linux / macOS** 出包并生成 Release 附件。

## 目录结构

```
src/
  main.js            主进程:托盘、余额面板、桌面宠物窗口、轮询、配置
  preload.js         安全桥(contextBridge)
  lib/adapters.js    协议探测(仅凭 API Base URL)+ Sub2API / New API / 专用站点余额适配
  lib/icon.js        纯 stdlib 的 PNG 编码 + 5x7 点阵字体(把紧凑金额画进托盘图标)
  renderer/          余额面板与设置界面(原生 HTML/CSS/JS)
  pet/               桌面宠物窗口(透明/穿透/拖动/右键/余额气泡)
assets/
  pet/               默认黑白猫吉祥物 01..09.png,按状态切换
scripts/
  gen_icons.js       生成应用图标
  test_adapters.js   适配器离线测试(npm test)
  pet-state-test.js  宠物状态切换测试(npm run test:pet)
  build-pet-assets.py 从素材源图重新生成 assets/pet/
  patch-deb-postinst.js 打包后向 deb 的 postinst 追加 SUID 沙箱修复
```
